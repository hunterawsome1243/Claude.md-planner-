# History

Shipyard Planner was built in 76 rounds in October 2026, each adding a feature or fixing what a review found. Version 15 (round 76) is the first public release. The tests for round N are in `test/features/rN/`.

The notes below were written as the work went. They name functions and settings in `src/app.js`, which helps when looking for the code behind a feature. They also mention review reports, patch scripts and test file names from the original working folder; those are not in this repository, and round tests now end in `.test.js`.
